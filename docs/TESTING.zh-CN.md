# 验证记录

本文件记录开发过程中在作者机器上的实测结果（Apple M5 / 24 GB / macOS 26），数字只代表该环境。测试命令见 [README.zh-CN.md](../README.zh-CN.md#测试)。英文摘要见 [TESTING.md](TESTING.md)。

环境：Apple M5 / 24 GB / macOS 26。当前测试对象为 0.2.0 本机临时签名构建。所有模型质量示例来自公开合成法语课堂。

- 本地法语识别资源、TranslateGemma 4B、Gemma 3 4B 可用。
- 记录保存与重读、SRT 导出、草稿修订去重、过期版本隔离、项目移动、软删除恢复、助手消息保存：自动检查通过。项目移动测试曾发现 URL 对象比较导致误删目标文件，已改为规范化路径比较，并重新通过检查。
- 原生界面实测：创建项目、导入音频、课堂重命名、移动项目、删除到最近删除、恢复。旧记录仍可在最近删除中恢复。
- 本地纪要和问答：保留 1 月、2.5%→3.75% 及实际 [00:20] 引用。模型最初漏掉引用，已增加用户提示、缺引用重试和失败提示，修正后的检查通过。引用标签存在不代表所有观点自动正确。
- 麦克风实际扬声器回放、系统声音 QuickTime 回放、暂停继续结束已通过；本机临时签名改变时必须重新绑定权限。
- 约 33 秒公开样例按原速转写，单段模型推理约 0.1–1.0 秒。推理耗时不含讲话、识别稳定和分句等待。

## 20 分钟核心管线测试

源音频 1216.0 秒（公开课堂样例连续重复），墙钟 1261.2 秒，328 段译文；峰值待处理队列 4，保存与重新打开通过。该阶段包含旧版标点片段，后续已经过滤。运行中重启模型服务触发过系统翻译回退，并恢复 Gemma。

后端调用耗时中位数 0.373 秒，P95 0.744 秒，最大 1.093 秒；这些是混合 Gemma / 系统回退的调用时间，不能解释成完整字幕端到端延迟，也不能声称整次全程 Gemma。持续回放期间未见不断增长的队列。

核心程序输出通过（当时的测试包装脚本收尾有一处与测试无关的 shell 引号错误，已修正）。20 分钟统计保留原始限制，不把它描述为最新完整 UI 的 20 分钟验收。

## 0.5.2 实时字幕与翻译

用户反馈"讲话时字幕停住，隔一阵冒出一整段"。在不接麦克风的整窗口实时回放中，以及两次现场麦克风测试中（独立测试版、临时课堂库），都没有复现这个问题。识别约每 0.9 秒送来一批结果，比声音慢约 0.07 秒；音频没有断续或积压；说话期间主线程最长卡顿低于 190 毫秒。根因仍未确认，诊断工具保留：启动参数 `-ClairClassDataRoot <临时目录> -ClairClassSpeechDiagnostics`，只记录时间和数字，不记录音频或文字。

本版修复两点：
- 已翻译句子的法语被修改后，旧中文先调暗保留，新译文到了原地替换，不再清空后重新出现、带动下面的字幕跳动。
- 草稿末尾未说完的半句改为停止变化 1.3 秒后再翻译。回放中，被丢弃的翻译请求从 136–142 次降到 0 次，模型忙碌时间从 91–95 秒降到 29 秒；中文出现的时间不变。

4 分钟现场测试中，50 次中文更新有 45 次原地替换，5 次仍被清空。这 5 次都是识别器调整了语音段的起点，新旧文字只差标点或大小写，留待后续处理。

## 仍有的限制

未测试真实课堂的口音、噪声及专业术语；12B 未下载、未实测。不是 macOS 公证发行版；不同 Mac 的权限、首次语言资源下载仍需现场验证。当前固定法语→简体中文，两种音源不能同时混合。

当前源码再验证：32.865 秒公开音频按原速运行，7 段实际语句全部使用 Gemma，峰值队列 2，墙钟 34.721 秒，保存重读通过。调用耗时 0.344–0.799 秒；进程干净退出 0。

最终引用修正：界面样例曾出现百分比正确、引用相邻片段的问题。现对百分比进行数字来源核对：只有转录中唯一匹配的时间片段才能自动标注「数字来源」，有歧义不自动归属；不支持的引用会重试或提示失败。数字来源一致性正反例及本机纪要问答复测通过。该检查不替代语义事实核查。

关闭主窗口时主动结束采集、保存并退出；修正后的进程退出已验证。

### 0.3.0 追加：翻译质量与抗干扰

用公开合成语音测量（参考文本已知），翻译统一使用本机 TranslateGemma 4B：

- 识别抗噪（词错误率 WER）：干净 0.000；白噪 10 dB / 0 dB 为 0.000 / 0.032；人声干扰 5 dB 0.000、0 dB 0.330、−5 dB 0.936；远场回声 + 人声 0.585。真正的弱点是背景人声和回声，不是稳态噪声。
- 试过但未采用（无可测收益或变差）：Apple 语音检测模块（各条件 WER 完全相同）、课程词汇提示（完全相同）、Apple 声音隔离预处理（白噪 0 dB 0.032→0.202，人声 0 dB 0.330→0.862，远场 0.585→0.947）。麦克风系统降噪属于同类处理，未能在文件上测量，因此未默认开启。
- 置信度：合成语音句级 ≥ 0.93，但用户真实麦克风录音句级中位数仅 0.73（多数词正确），因此不再按整句可信度提示。
- 停顿切句：同一段 37.8 秒讲课（7 处句中停顿），旧版产生 7 行、4 行半句；新版 4 行、1 行半句（识别漏掉句号所致），译文按整句生成。停顿本身使该语音的 WER 从 0.19 升到 0.32。
- 旧数据中 14.5%（57/393）的句子由系统翻译回退完成、14% 为半句；现在回退句在空闲时自动用 Gemma 重译。
- 模型服务被强制结束后，App 在 3 秒内自动重启服务（实测）。实时管线（公开样例与停顿讲课）全部 Gemma 通过；单元测试新增合并、语气词清理、法语书名号句末判断。
- 未验证：真实教室录音（口音、学生发言、空调声）；麦克风实时采集。说话人分离按用户决定本版不做。

### 0.3.0 追加：存疑标注校准

用户反馈存疑标注过多（真实麦克风课堂 15/15 句被提示，23% 的词被标出，多为 ce、il、le 等虚词）。用 16 段测试录音（3 种声音、8 种干扰）共 928 个与参考文本逐词对齐的词校准：

| 规则 | 每百词标注 | 标注中确为误识别 | 覆盖的误识别 |
|---|---|---|---|
| 旧：全部词，可信度 < 0.6 | 11.7 | 47% | 59% |
| 新：仅实词，可信度 < 0.5 | 2.7 | 68% | 20% |

新规则在用户那堂课上：标注词 47 → 最多 13，整句提示 15 → 1。正在识别的句子不再标注；设置中可关闭。代价是覆盖率下降，更多误识别不会被标出。
